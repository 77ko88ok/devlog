# Rustを学ぶ

### 細かい記法の話
- Rustにおける :: は パス　[Paths](https://doc.rust-lang.org/reference/paths.html)
- パスは、アイテム・値・タイプ・マクロ・属性の参照に用いる
- Rustにおける . は　メソッドの参照か呼び出し [Methods](https://doc.rust-lang.org/book/ch05-03-method-syntax.html)
